# 靶域 Range Zero

Android 离线第一人称射击试玩。自由移动、手动瞄准、开火换弹，随时练枪或与人机对战。

本仓库用于安装包分发和版本检查。

- [下载最新版本](https://github.com/junnhwan/range-zero/releases/latest)
- [查看全部版本](https://github.com/junnhwan/range-zero/releases)

## 试玩内容

- 原创石墙、木箱练场，提供靶场与 5 分钟人机对局。
- 一把 M4A1、12 款免费原创涂装，皮肤只改变外观。
- 左侧移动、右侧转向，开火键支持按住并拖动瞄准；支持多指操作、开镜、换弹和跳跃。
- 三档难度、快速复活、随时暂停，设置与皮肤保存在本机。
- 默认 30 帧上限，关闭实时阴影与反射；设置中可选 60 帧。

## 安装与更新

从 Releases 下载 `RangeZero-版本号-android.apk` 并在安卓手机安装。Android 7.0 起，需支持 OpenGL ES 3.0。

0.1.2 起，可在“操作设置 → 检查更新”查看新版；发现更新后点击“下载新版”，在系统浏览器下载并安装。也可直接访问上面的下载链接。对局与本地资源无需联网；手动检查更新需要连接 GitHub。

当前仍是试玩原型。已进行桌面引擎与 Android 模拟器检查，真实手机的流畅度、发热和操作手感仍需实际试玩确认。

## 更新清单与许可

`latest.json` 记录公开版本、递增版本码、APK 地址、字节数、SHA-256 和更新说明；对应文件也随每次 Release 发布。`SHA256SUMS.txt` 用于核对下载文件。

游戏模型、基础动画、贴图、字体和引擎的署名及许可保存在 APK 的“关于与许可”页面；公开许可说明随发布资料提供。
